# Design

## Theme

Players use this during prep and at the table. The page should feel like a clean dark reference sheet for a cursed fantasy one-shot: readable first, atmospheric second.

## Color

Use OKLCH tokens. Keep the palette dark, warm, and restrained:

- Background: near-black charcoal.
- Surface: warm charcoal.
- Raised surface: iron brown-gray.
- Text: smoke-tinted off-white.
- Muted text: ash gray.
- Primary accent: tarnished brass.
- Danger accent: dried blood.
- Positive accent: oxidized green.

## Typography

Use a native sans stack for rules and forms. Use a restrained system serif only for the product title and section headings. Keep body text at 15 to 16px and keep prose line length around 72ch.

## Layout

Use a fixed left navigation on desktop, compact top navigation on mobile, and a single main rules column. Panels are only for functional groups: rule tables, class details, weapons, Boons/Banes, negotiation, and the printable sheet.

## Components

- Navigation: simple links with current-section state.
- Search: one global filter for rules, classes, weapons, Boons, Banes, and negotiation.
- Filters: simple buttons for All, Boons, and Banes.
- Character sheet: print-friendly fields and checkboxes.
- Tables: dense, readable, horizontal scroll on small screens.

## Motion

Use short color transitions only. Respect reduced motion. No decorative page-load choreography.

## Imagery

Use the generated market image as the only primary visual asset. Do not let it turn into a blurred or decorative background.
