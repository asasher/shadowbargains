# Product

## Register

product

## Users

Shadow Bargains is for tabletop roleplaying groups who want a fast d20 one-shot: familiar enough for 5e players, lighter than 5e, combat-capable, and built around dramatic power-with-a-cost characters.

Users need to create characters in about 10 minutes, explain the rules quickly at the table, resolve combat without class-feature overhead, and run important social scenes with tactical structure.

## Product Purpose

The product turns the original Shadow Bargains concept into a single HTML rules reference. The rules model is:

- Three stats: Might, Guile, Will, built from a 3-point budget.
- One class from Stalker, Blade, Hex, Saint, Shade, Beast. It requires a key stat and gates available weapons, Boons, and Banes.
- One Boon and one Bane at character creation.
- Fast d20 roll-high resolution.
- Simple HP, Defense, damage dice, and turn actions.
- Draw Steel-style negotiation scenes using Interest, Patience, Motivations, and Pitfalls.

## Brand Personality

Sharp, cursed, practical. The voice should feel like a clean one-shot handout with dark fantasy pressure, not a full occult rulebook.

## Anti-references

Avoid generic fantasy parchment, sprawling 5e class pages, OSR zine clutter, neon cyberpunk dashboards, soft SaaS gradients, and any rules drift toward five stats, skill lists, resource currencies, or long-term campaign systems.

## Design Principles

- Preserve the original mechanics before polishing presentation.
- Table speed first: character creation, combat, and negotiation must be explainable fast.
- Make Boons and Banes character texture, not a bloated subsystem.
- Keep combat and roleplay linked: every fight has a social exit, every negotiation has a violent risk.
- Terminology discipline: use Banes consistently.

## Accessibility & Inclusion

Target WCAG AA contrast for body text and controls. Support keyboard navigation, visible focus states, reduced motion preferences, and mobile reading. Avoid relying on color alone for Boon/Bane distinctions.
